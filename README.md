# Vocal Placer

A browser-based media layering tool inspired by Vocal Placer.

## Features

- Upload videos, images, GIFs, and audio files
- Drag elements on the preview canvas to reposition them
- Drag clips on the timeline to change when they appear
- Layer ordering (lower rows appear on top)
- Playback controls with playhead
- Aspect ratio options (16:9, 9:16, 1:1)
- Size, speed, and volume controls
- Separate vocal and re-pronounce
- Download/export the finished composition

## How to use

1. Open index.html in any modern browser (Chrome, Edge, Firefox).
2. Click + Upload or drag files into the drop zone.
3. Adjust position, size, timing, and audio as needed.
4. Click Download to export.

All processing happens locally in your browser.
